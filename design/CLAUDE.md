# Design Directory

This trimmed repo keeps design light: one game, one brief.

- `design/game-brief.md` is the design record (written by `/brainstorm` or `/prototype`,
  read by `/cut`). Its Features list is the build order: `[ ]` not built, `[x]` built,
  `[-]` cut.
- Tuning numbers live in the game's `TUNE` block (`prototypes/<name>/game.js`), not here.
- `design/registry/entities.yaml` is a leftover cross-document registry; nothing in this repo
  writes it.
